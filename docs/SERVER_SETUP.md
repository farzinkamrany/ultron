# راهنمای کامل راه‌اندازی سرور اختصاصی لینوکس (VDS ژاپن) برای Ultron V5

این داکیومنت شامل تمام مراحلی است که برای راه‌اندازی صفر تا صد سرور لینوکس (Ubuntu) و دیپلوی کردن ربات Ultron V5 نیاز دارید.

## ۱. اتصال به سرور
ابتدا در ویندوز خود برنامه `Command Prompt` (CMD) را باز کرده و دستور زیر را وارد کنید:
```bash
ssh root@آی‌پیِ_سرور
```
- در صورت پرسش برای تایید اتصال، کلمه‌ی `yes` را تایپ کنید.
- پسورد سرور را کپی کرده و در صفحه مشکی **فقط یک بار کلیک راست کنید** (پسورد نمایش داده نمی‌شود) و `Enter` بزنید.

## ۲. نصب پیش‌نیازها
پس از ورود به سرور لینوکس، تمام پیش‌نیازها (Node.js نسخه ۲۰، Git و PM2) را با یک دستور نصب کنید:
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | bash - && apt-get install -y nodejs git && npm install -g pm2
```

## ۳. دریافت کدها و آماده‌سازی
کدهای پروژه را از ریپازیتوری گیت‌هاب خود دانلود کرده و پکیج‌ها را نصب و بیلد کنید:
```bash
git clone https://github.com/YOUR_USERNAME/ultron.git
cd ultron
npm install
npm run build
```
*(توجه: آدرس گیت‌هاب خود را جایگزین `YOUR_USERNAME` کنید)*

## ۴. تنظیم متغیرهای محیطی (.env)
دستور زیر را بزنید تا یک ویرایشگر متن باز شود:
```bash
nano .env
```
محتویات فایل `.env.local` کامپیوتر خود را در این فایل کپی کنید (با کلیک راست پیست می‌شود).
مهم‌ترین متغیرها:
```env
# برای ترید مجازی و شبیه‌سازی
TRADE_MODE=PAPER

# توکن‌های تلگرام و دیتابیس خود را حتماً قرار دهید
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
SUPABASE_URL=...
SUPABASE_SERVICE_ROLE_KEY=...
```
**نحوه ذخیره در nano:** دکمه‌های `Ctrl + X` را بزنید، سپس دکمه `Y` و در نهایت `Enter` را بزنید.

## ۵. روشن کردن دائمی موتور با PM2
با دستور زیر، ربات را در پس‌زمینه سرور روشن کنید تا با بستن ترمینال خاموش نشود:
```bash
pm2 start npm --name "ultron" -- start
```

## ۶. تنظیم زمان‌بندی (Cron Jobs)
ربات‌های مگالودون و لویاتان نیاز دارند دقیقاً سر هر ۴ ساعت (۱ دقیقه پس از بسته شدن کندل ۴ ساعته) بیدار شوند. برای این کار:
```bash
crontab -e
```
*(اگر از شما شماره ادیتور پرسید، عدد 1 یعنی nano را انتخاب کنید)*
در پایین‌ترین خط خالیِ فایل، این دو دستور را قرار دهید:
```bash
1 */4 * * * curl -s http://localhost:3000/api/cron/orchestrator
0 */4 * * * curl -s http://localhost:3000/api/cron/cto
```
سپس با `Ctrl + X` و `Y` و `Enter` ذخیره کنید.

## نکات کلیدی و طلایی

### الف) اتصال به Hyperliquid و خطای Deposit
- برای ساخت کلیدهای API (API Wallet Address و Private Key) در سایت Hyperliquid، باید حتماً حداقل ۱ بار (حتی ۵ دلار USDC در شبکه Arbitrum) به ولت خود واریز داشته باشید. 
- در صورت صفر بودن موجودی، ارور `Must deposit before performing actions` دریافت خواهید کرد. این یک سیستم ضد اسپم از سمت صرافی است.
- **در حالت PAPER (مجازی):** نیازی به کلیدهای Hyperliquid ندارید! ربات به صورت عمومی قیمت‌ها را می‌خواند و نتایج را در دیتابیس شما (Supabase) ذخیره می‌کند.

### ب) نحوه آپدیت کردن سرور در آینده
اگر تغییراتی روی کدهای سیستم کامپیوتر خود دادید و روی گیت‌هاب Push کردید، برای آپدیت شدن سرور ژاپن فقط کافیست به سرور متصل شده (مرحله ۱)، وارد پوشه شوید و سه دستور زیر را بزنید:
```bash
cd ultron
git pull
npm run build
pm2 restart ultron
```

### ج) اتصال ربات تلگرامی
از آنجایی که سرور ژاپن یک IP ساده دارد و دارای پروتکل امن `https` نیست، تلگرام اجازه اتصال Webhook به آن را نمی‌دهد. 
بهترین راه این است که موتور ترید را روی **سرور ژاپن** اجرا کنید، اما پروژه را برای ارتباط تلگرامی روی **Vercel** هم دیپلوی کنید. هر دو به یک دیتابیس مشترک وصل می‌شوند و بی‌نقص در کنار هم کار خواهند کرد.
